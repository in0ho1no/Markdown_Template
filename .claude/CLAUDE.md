## 画像ファイル名ルール

Markdown に埋め込む画像を追加・参照するときは、次のルールに従う。

- 画像ファイル名は、ASCII の英数字、ハイフン、アンダースコア、ドットだけで構成し、内容を表す英単語で付ける(例: `setup-flow.png`)。
- 日本語などの非 ASCII 文字と空白文字は、画像ファイル名にも画像を置くフォルダ名にも使用しない。
- Markdown Preview Enhanced の画像埋め込み(`embed_local_images`)は、日本語や空白文字を含むファイル名に対応していない。埋め込みに失敗しても見た目では気付きにくいため、ファイル名の段階で防ぐ。
- 画像の alt テキストは日本語でよい。このルールの対象はファイル名とフォルダ名だけとする。
- 日本語や空白文字を含む既存の画像ファイルを見つけた場合は、英語名(ASCII のみ)にリネームし、参照している箇所をすべて更新する。
